# Protein-supply benchmark: reproduction boundary

**Public summary of retained reproduction documentation.** The empirical study is annual and univariate, using four national supply series. It is not a causal, monthly/quarterly or tax-benefit model. The 2035 endpoint is an analyst assumption.

The original reproduction workflow writes a separate timestamped experiment rather than overwriting frozen results. Source vintage, hashes, package versions, seed and original output preservation are required to compare runs. A later download from a mutable source URL is not the same vintage unless its checksum matches. The benchmark is frozen; this dashboard does not claim an executable environment or a new numerical rerun.

Long-horizon distributions are uncalibrated. Historical pretrained-model overlap is unresolved; the pretrained candidate was excluded from primary selection. Source integrity checks and code tests do not establish qualified scholarly acceptance.
