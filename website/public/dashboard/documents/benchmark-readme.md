# Protein-supply benchmark: historical scope

**Public summary of frozen exploratory research.** The outcome is national available protein supply, not alternative-protein adoption or individual intake. Human scholarly review remains pending.

The retained benchmark uses 56 frozen FAOSTAT estimates: total and animal-origin supply, 2010–2023, in India and Pakistan. Six implementations cover naive, classical, regression and pretrained forecasting. With only two distinct selection years, the protocol defaults to persistence for all four series. Nominal 80% intervals cover 1/6 held-out cells in each Indian series and 6/6 in each Pakistani series. Cells overlap; neither result establishes calibration. Forecasts through 2035 remain exploratory extrapolations.

This dashboard contains the source-status summary, not a fresh benchmark rerun or a national adoption forecast.
