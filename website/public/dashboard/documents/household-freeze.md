# Household-demand workstream freeze

Frozen on 22 October 2026: the wider household-demand model is not part of the current India–Pakistan report contribution. Household modelling, interactive diagnostics and further acquisition remain frozen. The separately retained 60-response forecast panel remains an active report input.

Any future extension requires a named report-linked question, explicit empirical inputs, acceptance checks and stopping conditions.
