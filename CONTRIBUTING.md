# Reviewing this edition

Start with the claim register, then read the cited original and the transformation that supports the statement. Record reviewer, date, disposition and any correction. Reviewers should distinguish arithmetic agreement from empirical support, factual verification from scholarly acceptance, and individual author approval from team agreement.

For numerical changes, preserve the original input and its source, document the new vintage and units, and regenerate the outputs. Do not update the reference files merely to make a failing check pass. First explain the scientific change and inspect its effects on the chapter, tables and sensitivities. A missing observation remains missing.

The panel's accepted count must not be changed by hiding rejected, errored or incomplete attempts. Preserve model identity limits, parser changes and unequal evidence conditioning. The original instruments and execution logs are retained privately; they are not necessary for offline table reproduction and are not licensed for redistribution here.

Run the commands in README after changing numerical code or data. For prose changes, check every affected claim, local link and generated document. Final human verification includes reading, running and testing included code. Complete author and source-rights review before any final submission or public release.
